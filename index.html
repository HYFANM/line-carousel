1
去 LINE Developers Console → 建立 LINE Login Channel

          
2
在 Channel 內建立 LIFF App：Size 選 Full，開啟 shareTargetPicker 並同意條款

          
3
Endpoint URL 填入這個 HTML 的公開網址（可用 GitHub Pages），複製 LIFF ID 貼到上方欄位

          
4
去 Cloudinary 免費註冊 → Settings → Upload → Add upload preset → Signing Mode 選 Unsigned → 填入上方欄位

          
5
在 LINE App 內開啟 liff.line.me/你的LIFF_ID → 填好卡片 → 按「分享給好友」

          
!
必須在 LINE 內建瀏覽器開啟才能呼叫分享。電腦瀏覽器請改用「複製 JSON」。
