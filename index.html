1
去 LINE Developers Console 用你的 LINE 帳號登入

          
2
建立 Provider（任意名稱）→ 點 「Create a LIFF app」 → Size 選 Full，打開 shareTargetPicker

          
3
Endpoint URL 填入這個 HTML 的公開網址（可用 GitHub Pages 或 Netlify 免費部署）

          
4
建立後複製 LIFF ID（格式：1234567890-AbCdEfGh）→ 貼到上方欄位 → 按「連線」

          
5
回到編輯頁，填好所有卡片 → 按下方 「分享給好友」

          
6
LINE 彈出好友選擇器 → 選人 → 送出 ✓ 對方收到的是你個人帳號發的可滑動卡片

          
!
此頁面必須在 LINE App 內部瀏覽器開啟才能呼叫分享。普通瀏覽器請改用下方「複製 JSON」備用。
